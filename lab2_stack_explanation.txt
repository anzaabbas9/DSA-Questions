------------------------------------------------------------
SUMMARY OF CODE SCOPE TYPES USED IN THIS FILE
------------------------------------------------------------

1. Global scope
- Variables/functions declared outside any function
- Example: SIZE, top, stack, and isbalanced

2. Local scope
- Variables declared inside functions or blocks
- Example: ch, x, item, expression, character, opening

3. Block scope
- Code inside loops, if/else, switch, or braces
- Example: the do-while menu loop and the for loop inside isbalanced

4. Function scope
- Each function has its own local environment
- Example: main(), push(), pop(), peek(), display(), isbalanced()

5. Loop scope
- Variables declared within a for loop stay inside that loop block
- Example: int i = top, int j = 0, and char character in the loop

------------------------------------------------------------
What this final active code is doing
------------------------------------------------------------
The final working program uses a stack to verify whether a bracket sequence is valid.
Examples:
- (a+b) -> Balanced
- [2 + {3*4}] -> Balanced
- (a + [b] -> Not balanced
- {[(])} -> Not balanced

Algorithm:
1. Read the expression.
2. Traverse every character.
3. If it is an opening bracket, push it onto the stack.
4. If it is a closing bracket, check the top of the stack.
5. If it matches, pop it.
6. If not, return false.
7. After processing the full string, if the stack is empty, the expression is balanced.

This is a standard stack-based matching method used in expression validation.
